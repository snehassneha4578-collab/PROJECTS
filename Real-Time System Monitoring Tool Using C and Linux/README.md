## 📌 Project Overview

The Real-Time System Monitoring Tool is a Linux-based system monitoring application developed using Pure C Programming.

The project monitors important system resources and helps understand operating system resource management.

### Monitored Resources

🖥️ CPU Usage  
🧠 Memory Usage  
💾 Disk Usage  
⚙️ Process Information  

---

## 🎯 Objectives

- Develop a real-time monitoring tool using C
- Understand Linux system programming
- Access system information in Linux
- Monitor hardware resources
- Learn operating system concepts
