# 📖 Project Overview

The **IoT Child Tracking System** is a **hardware-based mini project** designed to improve child safety by enabling real-time location tracking using IoT and embedded system technologies. The system collects location information through GPS and transmits it wirelessly for remote monitoring.

---

# 🎯 Objective

- 👨‍👩‍👧 Ensure child safety through location tracking.
- 📍 Provide real-time location monitoring.
- 🌐 Demonstrate IoT-based embedded system implementation.
- 📡 Enable wireless communication between hardware devices.

---

# 🛠️ Hardware Components

- 🔹 Arduino / ESP32
- 🔹 GPS Module
- 🔹 GSM Module
- 🔹 Power Supply
- 🔹 Breadboard
- 🔹 Connecting Wires

---

# 💻 Software Used

- Arduino IDE
- Embedded C Programming

---

# ⚙️ Working Principle

1. 📍 GPS module receives the current location.
2. ⚡ Microcontroller processes the location data.
3. 📡 GSM module transmits the location.
4. 👨‍👩‍👧 Parent receives the location information for monitoring.
