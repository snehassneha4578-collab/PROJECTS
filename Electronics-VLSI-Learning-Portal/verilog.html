What is Verilog?

Verilog is a Hardware Description Language (HDL) used to describe, design and verify digital electronic systems.

Applications of Verilog

  • ASIC Design
  • FPGA Programming
  • Digital Circuit Design
  • RTL Development
  • Functional Verification

Basic Verilog Concepts

Concept Description
Module Basic building block used to describe hardware
Port Input and output connections of a module
Wire Used for connecting hardware elements
Reg Stores values in procedural blocks
Always Block Used to describe sequential and combinational logic

Simple AND Gate Example


module and_gate(
input A,
input B,
output Y
);

assign Y = A & B;

endmodule
