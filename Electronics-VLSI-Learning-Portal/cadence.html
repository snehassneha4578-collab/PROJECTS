What is Cadence Virtuoso?

Cadence Virtuoso is an Electronic Design Automation (EDA) tool used for designing, simulating and verifying integrated circuits.

Applications of Cadence

  • Analog IC Design
  • CMOS Circuit Design
  • Schematic Creation
  • Layout Design
  • Circuit Simulation
  • Physical Verification

VLSI Design using Cadence

Stage Description
Schematic Design Creating circuit diagrams using electronic components
Simulation Checking circuit performance and waveforms
Layout Design Creating physical representation of the IC
DRC Design Rule Checking for manufacturing accuracy
LVS Layout Versus Schematic verification
