# 📌 About The Project

🌟 **Linux System Monitoring Tool** is a Bash-based command-line application used to monitor important Linux system resources.

This tool provides real-time information about:

🟢 CPU Usage  
🟢 Memory Usage  
🟢 Disk Usage  
🟢 Network Information  
🟢 Running Processes  
🟢 System Uptime

# ⚙️ How To Run

## Step 1: Clone Repository

```bash
git clone <repository-link>
```

## Step 2: Enter Project Directory

```bash
cd Linux-System-Monitoring-Tool
```

## Step 3: Give Execute Permission

```bash
chmod +x monitor.sh
```

## Step 4: Run Application

```bash
./monitor.sh
```

# 📊 Linux Commands Used

| Monitoring | Command |
|---|---|
| 🕒 Date & Time | `date` |
| 🧠 Memory Usage | `free -h` |
| 💾 Disk Usage | `df -h` |
| ⚡ CPU Usage | `top` |
| 🌐 Network Details | `ip addr` |
| 📋 Processes | `ps aux` |
| ⏱️ System Uptime | `uptime` |

# 📝 Logging System

The log file stores:
