# 🖥️ Linux System Monitoring Tool

A Bash-based Linux System Monitoring Tool that provides real-time system information through a simple menu-driven interface.

## 🚀 Features

✅ Date and Time Monitoring  
✅ Memory Usage Monitoring  
✅ Disk Usage Monitoring  
✅ CPU Usage Monitoring  
✅ Network Information  
✅ Running Processes Monitoring  
✅ System Uptime Monitoring  
✅ Log File Generation  
✅ Colorful Terminal Interface  

## 🛠️ Technologies Used

- Linux
- Bash Shell Scripting
- Ubuntu Terminal
- Git & GitHub
